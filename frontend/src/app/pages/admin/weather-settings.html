Météo

Ces réglages bornent les jauges de température du tableau de bord sur le min/max prévisionnel de la journée (Open-Meteo), sans marge ajoutée — les extrêmes prévus s'affichent tels quels. La localisation se définit par webhook (un webhook regroupe les capteurs d'un même lieu physique) — ou par capteur pour un capteur autonome, hors webhook. Tant que la config est vide ou que l'appel échoue, une jauge retombe sur le repli fixe -5°C/+45°C.

Comment renseigner la localisation

Un simple nom de ville suffit (ex : Paris, Tours). Il est géocodé automatiquement via l'API Adresse (Base Adresse Nationale), puis envoyé à Open-Meteo pour la prévision du jour — pas besoin de code INSEE ni de coordonnées, et aucune clé ni inscription requise.
