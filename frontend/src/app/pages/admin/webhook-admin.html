Webhooks

Un webhook est un point d'ingestion HTTP partagé par plusieurs capteurs d'une même application réseau (application TTN, Application ChirpStack, Flow Helium…). Configurez-le une seule fois côté réseau LoRa, puis rattachez-y chacun de vos capteurs depuis leur page « Connexion » — le routage vers le bon capteur se fait automatiquement via l'identifiant de device porté par chaque uplink.
